# Portofolio Prakoso

Selamat datang di proyek website portofolio pribadi Anda! Website ini dirancang dengan estetika modern, premium, dan responsif menggunakan **Vite**, **Vanilla JavaScript**, dan **CSS3**.

## Struktur Menu
- **Beranda**: Halaman utama dengan pesan selamat datang yang menarik.
- **Portfolio**: Galeri proyek unggulan Anda lengkap dengan deskripsi dan teknologi yang digunakan.
- **Timeline**: Riwayat perjalanan karir Anda dalam bentuk timeline yang elegan.
- **About Me**: Informasi lebih mendalam tentang siapa Anda dan keahlian yang Anda miliki.

## Teknologi Utama
- **HTML5 & CSS3**: Menggunakan teknik Glassmorphism dan animasi modern.
- **JavaScript**: Untuk interaksi halus (smooth scroll) dan animasi saat scroll.
- **Google Fonts**: Menggunakan font 'Outfit' untuk tampilan profesional.

## Cara Menjalankan Project
Jika Anda ingin melanjutkan pengembangan di komputer sendiri:
1. Pastikan Node.js sudah terinstal.
2. Jalankan `npm install` untuk menginstal dependensi.
3. Jalankan `npm run dev` untuk memulai server pengembangan.
4. Buka `http://localhost:5173` di browser Anda.

## Cara Menyesuaikan Konten
- **Edit Teks**: Buka file `index.html` dan cari bagian yang ingin diubah.
- **Ganti Gambar**: Folder `public/` bisa digunakan untuk menyimpan gambar Anda, lalu update atribut `src` pada tag `img` di `index.html`.
- **Ubah Warna**: Buka `src/style.css` dan sesuaikan variabel di bagian `:root`.
